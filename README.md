# MianT2API
通过自研转换工具+提示词注入，实现将DeepSeek网页端转换为Open AI兼容格式API服务，支持接入主流Agent工具，并且可调用工具、MCP等，新增加模型输出复查功能，大大提升结果的准确性。

出于安全考虑，本项目将只开源部分源码（核心程序），需要自己修改源码完成账号添加功能。

该工具在不开启 复查 模式时只需要4-6个及以上账号即可满足个人日常开发，但该模式下容易出现工具调用失败、反复调用等不确定因素，但可以正常使用（本人推荐开启复查模式，尤其是开发重要项目）。

在开启 复查 模式后，则最低需要8个账号，推荐12个及以上账号。开启 复查 模式后工具、MCP调用更稳定，模型回复更准确，8-12个账号依然只能满足个人日常开发。
